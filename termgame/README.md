# TermGame — Game Top-up Platform

A full-stack web application designed for game top-up services, featuring customer workflows, user authentication, and administrative management.

## Overview

TermGame is a game top-up platform built to manage digital product orders and provide a structured purchasing experience for customers.

The application includes customer-facing functionality, administrative workflows, and payment integration.

## Key Features

- **User Authentication:** Supports registered users and guest access.
- **Product Management:** Organizes game top-up products and related information.
- **Order Management:** Supports customer purchasing workflows.
- **Admin Dashboard:** Provides administrative functionality for managing the platform.
- **Payment Integration:** Integrates Stripe API for payment processing.
- **Database Management:** Uses Prisma ORM to interact with the SQL database.

## Technology Stack

| Category | Technologies |
|---|---|
| Frontend | Next.js |
| Backend | Next.js |
| ORM | Prisma |
| Database | SQL |
| Payment | Stripe API |

## System Architecture

1. **Frontend:** Provides the customer-facing shopping experience.
2. **Application Logic:** Handles authentication, product, and order workflows.
3. **Database Layer:** Uses Prisma to manage database operations.
4. **Payment Integration:** Connects with Stripe API for payment processing.
5. **Administration:** Supports administrative operations.
