# AI Product Moderation System

An AI-powered product moderation system developed for an e-commerce platform to assist with reviewing and managing product content.

## Overview

This project combines a web application with a Python-based AI backend to support product moderation workflows.

The system allows product information and images to be managed while integrating AI capabilities to assist with content review.

## Key Features

- **Product Management:** Manage product information through a web application.
- **AI Integration:** Connect the frontend application with a Python-based AI backend.
- **Product Moderation:** Support AI-assisted product content review.
- **Image Management:** Integrate Cloudinary for image storage and management.
- **Database Management:** Store product and application data using MongoDB.

## Technology Stack

| Category | Technologies |
|---|---|
| Frontend | Next.js |
| Backend / AI | Python |
| Database | MongoDB |
| Media Storage | Cloudinary |

## System Architecture

1. **Frontend:** Provides the user interface for product management.
2. **AI Backend:** Processes moderation-related requests using Python.
3. **Database:** Stores product information and related data in MongoDB.
4. **Image Storage:** Uses Cloudinary to manage product images.

## Development Highlights

- Developed a web application integrated with an AI backend.
- Connected frontend workflows with Python-based AI processing.
- Integrated database and cloud-based image management.
- Worked across frontend and AI backend components.
